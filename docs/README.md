# Documentation index

The documentation is grouped by purpose so operators, developers, and reviewers do not have to
search a flat folder.

## Start here

- `architecture/project-overview.md` - complete workflow, repository map, runtime boundaries, and
  technology inventory.
- `ai/surface-completion-blueprint.md` - evidence-first plan for predicting occluded surfaces.
- `viva/technical-question-bank.md` - technical questions and defensible answers.
- `contracts/api.md` - HTTP API and artifact handoff contract.
- `contracts/surface-completion-runtime.md` - protocol for connecting a trained AI runtime.
- `contracts/scientific-integrity.md` - provenance, confidence, and measurement rules.

## Supporting material

- `architecture/` - current system design and optional segmentation behavior.
- `benchmarks/` - matcher promotion evidence and comparison rules.
- `blockers/` - explicit evidence limitations and next actions.
- `evidence/` - delivery ledgers for backend and operator UI work.
- `guides/` - backend/operator demos, telemetry usage, and sample-data capture.
- `reviews/` - source-material and frontend/backend integration reviews.
