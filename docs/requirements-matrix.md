## Capability classification

- Implemented and meaningfully unit-tested: immutable inputs, scored/bounded selection, sparse orchestration, isolated attempts, output checksum validation, stage input/config/tool fingerprints, run locks, global heavy-job slots including segmentation/completion, managed segmentation cancellation/timeout cleanup, conservative surviving-child detection, capability reporting, scientific alignment gates, measurement persistence, bounded reviewed completion, topology/optional metric-depth coverage, readiness/export/benchmark reports, and fixture-validated OBJ/GLB/LAS writers.
- Implemented but runtime-unverified here: real COLMAP reconstruction after these changes, real YOLO masks, CPU/GPU fallback on the college server, OpenMVS/Metal/CUDA execution, cancellation of installed providers, reviewed real completion and ten-minute processing.
- Partial: visible-scene diagnostics (no reference denominator), geometry exporter large-scene/real-data validation, independent accuracy reporting (no reference set), sparse preview and gap-review handoff.
- Missing: GeoTIFF/FBX exporters; official accuracy protocol; reference completeness domain; representative 10-minute benchmark; server hardware results.

The earlier Pillow deprecation warning is fixed: contact-sheet resizing uses the supported
`Image.Resampling` API. No compatibility suppression was added.
